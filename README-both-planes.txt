EXPERIMENT MODES
1. Axis inclined to both HP and VP. The angle pair is constrained using sin²(alpha) + sin²(beta) <= 1.
2. Axis inclined to HP, with a selected polygon base edge inclined to VP.
3. Axis inclined to VP, with a selected polygon base edge inclined to HP.

Cylinder and cone use the axis-inclined-to-both-planes condition because they have no polygonal base edge. All 10 solids are available in the solid selector.

The front and top views are projected from the same transformed 3D vertices. The page uses a polygonal approximation for cylinder and cone. Please check the views against your prescribed engineering-drawing construction steps before classroom use. JavaScript syntax was checked; a live browser rendering test was not available during preparation.

How to interpret this experiment

  1. Select a solid and a geometric inclination condition.
  2. Set the angle or angles. For an axis inclined to both HP and VP, the page limits the angle pair to geometrically possible combinations.
  3. Observe how the same transformed vertices determine the 3D orientation, front view and top view.
  4. Choose the resting feature before setting angles. For corner contact, a base corner is selected and the two adjacent base edges are constrained to have equal inclinations to the contact plane. The axis can remain inclined to the other plane. An edge is reported as resting only when it is actually parallel to and supporting the selected plane. In the mixed conditions, the base edge is the required hinge and the reference plane is fixed by the construction.
  5. The drawing sheet shows the VP projection (front view) above XY and the HP projection (top view) below XY, generated from the same transformed 3D vertices.

This is an educational visualizer. Cylinders and cones use faceted polygonal geometry; edge visibility is estimated from the polygon faces. Check construction steps and contact conditions against the prescribed engineering-drawing method for the specific problem.

How to interpret this experiment

  1. Select a solid and a geometric inclination condition.
  2. Set the angle or angles. For an axis inclined to both HP and VP, the page limits the angle pair to geometrically possible combinations.
  3. Observe how the same transformed vertices determine the 3D orientation, front view and top view.
  4. For the base-edge conditions, choose which polygon base edge is used for the second inclination constraint. Curved solids do not have a polygonal base edge, so these conditions are disabled for cylinder and cone.

This is an educational visualizer. Check construction steps, contact conditions and visible/hidden-edge conventions against the prescribed engineering-drawing method for the specific problem.

This update simplifies navigation on phones and prepares it for future modules.

Replace these four navigation files in your existing GitHub repository:
- index.html
- style.css
- both-planes.html
- both-planes.css

The ZIP also includes the previously prepared Module 02 file both-planes.js, which supports the resting-condition controls. If you have already installed that exact Module 02 update, you do not need to replace it again. Do NOT replace the original page's app.js.

After uploading, commit changes and refresh both pages. Test the menu on a narrow phone screen.
